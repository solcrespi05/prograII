# Trabajo Decorator
En este proyecto se implementa un patron de diseño Decorador para uso en una cafeteria, permitiendo crear bebidas personalizadas. 

## Estructura: 
- bebidas.py : clase base de bebidas (Espresso, CafeDeLaCasa, CafeNegro). 
- condimentos.py :  decoradores para agregar condimentos (Mocha, Soja, Crema, Caramelo, DobleMocha)
- builder.py : Función para construir bebidas
- main.py: ejemplos ed uso y cafes
- test.py : testeo para verificar funcionamiento


*Los tests se corren desde la carpeta decorator, podes correr este comando en la terminal.  
python test.py

Personalización: se pueden seguir agregando bebidas y mas condimentos para poder hacer la bebida de tu preferencia. Tambien jugar con los tamaños, por default esta el chico.
